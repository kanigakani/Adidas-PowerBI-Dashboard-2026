# Adidas Sales & Revenue Analysis Dashboard

## Project Overview
This project analyzes Adidas US sales data using Microsoft Power BI.

## Tools Used
- Microsoft Power BI
- Power Query
- DAX
- Microsoft Excel

## Key Performance Indicators
- Total Revenue
- Total Profit
- Total Units Sold
- Total Transactions

## Dashboard Features
- Monthly Revenue Trend
- Revenue by Product
- Revenue by Region
- Revenue by Retailer
- Revenue by Sales Method
- Interactive Slicers

## Objective
To analyze sales performance, identify profitable products, understand regional performance, and generate useful business insights.
